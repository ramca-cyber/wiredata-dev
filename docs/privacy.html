WireData Privacy Policy

Network Data Workbench — Chrome Extension

Last updated: August 2026  ·  Version 0.1.0
Summary: WireData is a local-first, zero-telemetry developer tool. All captured data stays in your browser and local filesystem. WireData collects no personal information about you, transmits nothing to external servers, and has no analytics, tracking, or advertising of any kind.

Zero Telemetry Local-First No External Servers No Ads Open Source

1. What WireData Does

WireData is a Chrome developer tool that helps software developers and data analysts inspect, capture, and query structured JSON network traffic from web applications they are actively debugging.

When you explicitly click Start Capture, WireData temporarily monitors HTTP/HTTPS fetch and XMLHttpRequest responses on the active browser tab and records structured JSON response bodies into an in-memory or local-filesystem workspace.

2. Data We Collect About You

We collect nothing about you. Specifically:

  • No name, email address, or account information
  • No usage analytics or telemetry
  • No crash reports sent to external servers
  • No advertising identifiers
  • No browser history beyond the active tab session you explicitly start

3. Network Request Data Captured at Your Direction

When you start a capture session, WireData intercepts JSON API responses from the active tab you are inspecting. This captured data:

  • Stays entirely in your browser (chrome.storage or local filesystem via the File System Access API)
  • Is never transmitted to WireData's servers or any third party
  • Is only accessible to you within the WireData workbench UI
  • Is automatically cleared when you close the capture session or restart the browser
What is captured in regular (Side Panel) mode:
JSON response bodies only. Request URLs are sanitized to remove query parameters that may contain tokens or secrets. Request headers and request bodies are never stored. Capture stops immediately when you close the side panel or navigate away.
What is captured in DevTools mode:
Sanitized request URLs, response JSON, and (optionally) GraphQL operation names only. Authentication headers and credentials are never persisted.

4. Permissions Explained

  • activeTab — Temporarily inspect the tab you clicked the extension on. No persistent access to any website.
  • scripting — Inject temporary fetch/XHR intercept hooks and DOM table extractors, removed when capture stops.
  • sidePanel — Show the capture controller UI alongside your active tab.
  • storage / unlimitedStorage — Store captured datasets locally in your browser (IndexedDB). Nothing is sent externally.

5. Third-Party Services

WireData uses the following open-source components, all bundled and served locally:

  • DuckDB-WASM — In-browser SQL engine. Runs entirely client-side. No network calls.

WireData does not use any analytics SDKs, advertising networks, or external API services.

6. Data Sharing

WireData does not sell, rent, share, or transfer any captured data or any information about you to any third party under any circumstances.

7. Data Retention

All session state is stored in chrome.storage.session, which is automatically cleared when the browser restarts or the extension is reloaded. Workspace data you choose to save to local files stays on your machine and is under your full control.

8. Children's Privacy

WireData is a professional developer tool and is not directed at children under 13. We do not knowingly collect information from children.

9. Changes to This Policy

If we make material changes to this privacy policy, we will update the "Last updated" date at the top of this page and include a note in the Chrome Web Store changelog.

10. Contact

Questions about this privacy policy? Open an issue on the WireData GitHub repository.
